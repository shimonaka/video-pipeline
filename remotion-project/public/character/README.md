# 口形状アセットについて

このディレクトリには、キャラクターの口パク用画像を配置してください。

## 必要なファイル

以下の6種類の口形状画像が必要です:

| ファイル名 | 口形状 | 発音例 |
|-----------|-------|--------|
| `mouth-A.png` | 閉じた口（休止） | 無音、n |
| `mouth-B.png` | 少し開いた口 | m, b, p |
| `mouth-C.png` | 開いた口（楕円） | e, a |
| `mouth-D.png` | 大きく開いた口 | a, o |
| `mouth-E.png` | 横に引いた口 | i, e |
| `mouth-F.png` | 突き出した口 | u, o, w |

## 参考画像

`mouth-shapes-reference.png` を参考に、各口形状の画像を作成してください。

## 推奨サイズ

- **サイズ**: 256x256 px 程度
- **形式**: PNG（透過推奨）
- **スタイル**: キャラクターのデザインに合わせてください
